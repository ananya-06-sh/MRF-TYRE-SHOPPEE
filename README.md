# MRF Tyre Shop Manager

This ZIP is the structure-only starting point for the mobile-first inventory, billing, services, and TallyPrime application.

No packages are installed and no application logic has been added yet.

## Open in IntelliJ IDEA

1. Extract the ZIP.
2. Open IntelliJ IDEA.
3. Select **File > Open**.
4. Choose the extracted `MRF-Tyre-Shop` folder.
5. Select **Trust Project** if IntelliJ asks.

## Planned modules

- `frontend`: React + TypeScript + Tailwind user interface
- `backend`: Node.js + Express + TypeScript API
- `tally-connector`: local connector for the shop's Windows billing computer
- `docs`: product, API, database, and setup documentation

Our next baby step will be to create only the root project configuration files.
